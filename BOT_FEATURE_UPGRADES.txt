2. PRIORITY 1: SMART SEASON & EPISODE AUTO-GROUPER
================================================================================
PROBLEM:
When members search for a web series or K-drama with 16-50 episodes, the bot
outputs 20-50 separate file buttons spanning 5+ pages. This causes severe group
chat spam, slow pagination, and excessive Telegram callback queries.

SOLUTION / UPGRADE SPEC:
1. Regex Parser:
   Detect season and episode tags in file names:
   - Patterns: r'(?:S|Season\s*)(\d{1,2})', r'(?:E|EP|Episode\s*)(\d{1,3})'
2. Dynamic Grouping:
   If a query returns files from the same show with multiple episodes, collapse
   them into clean Season buttons:
     [ 📁 Season 1 (16 Episodes) ]   [ 📁 Season 2 (12 Episodes) ]
3. Sub-Keyboard On Click:
   Tapping "Season 1" reveals:
     [ Ep 1 ] [ Ep 2 ] [ Ep 3 ] [ Ep 4 ]
     [ Ep 5 ] [ Ep 6 ] [ Ep 7 ] [ Ep 8 ]
     [ ⚡ Send All Season 1 Files (Batch) ]
     [ 🔙 Back to Search ]

BENEFIT:
Chat clutter reduced by 85%. Users can grab entire seasons in a single tap.

3. PRIORITY 2: QUALITY & RESOLUTION FILTER BADGES (480p / 720p / 1080p / 4K)
================================================================================
PROBLEM:
Users on limited mobile data frequently tap 1080p or 4K files accidentally, or
users with fast Wi-Fi get frustrated digging through 480p files.

SOLUTION / UPGRADE SPEC:
1. Regex Tag Extraction:
   Parse the indexed file name:
   - 4K / UHD : 2160p, 4k, uhd
   - 1080p    : 1080p, fhd, fullhd
   - 720p     : 720p, hd
   - 480p     : 480p, sd
   - Codecs   : HEVC, x265, 10bit
2. Top Filter Row on Search Results:
   Display dynamic filter chips above the search results:
     [ 🎬 1080p (4) ]  [ 📺 720p (6) ]  [ 📱 480p (2) ]  [ All ]
3. Tapping a filter dynamically updates the inline keyboard without querying
   MongoDB again (cached in memory or callback data).

BENEFIT:
Fast, data-conscious downloading tailored to each user's network speed.

4. PRIORITY 3: FUZZY SEARCH & TYPO AUTO-CORRECTION ("DID YOU MEAN?")
================================================================================
PROBLEM:
Typing mistakes like "Avangers" instead of "Avengers" or "Stranger Thigns"
currently yield "0 files found", prompting angry user complaints.

SOLUTION / UPGRADE SPEC:
1. When MongoDB regex query returns 0 results:
   - Pass the query through a fuzzy matching utility (e.g., standard
     difflib.get_close_matches or Levenshtein distance against a cached set of
     popular indexed titles).
2. Bot Response:
   "⚠️ No exact matches found for 'Avangers'.
    💡 Did you mean: <b>Avengers (2012)</b>?
    
    [ 🔍 Search 'Avengers' ]"

BENEFIT:
Eliminates over 40% of false "file missing" complaints.

5. PRIORITY 4: /fsub COMMAND ALIAS & INTERACTIVE FSUB IMPROVEMENTS
================================================================================
PROBLEM:
Currently your bot uses `/set_fsub`. Admins often type `/fsub` expecting it
to work, leading to confusion.

SOLUTION / UPGRADE SPEC:
1. Add command aliases in `plugins/commands.py`:
   @Client.on_message(filters.command(['set_fsub', 'fsub']))
2. Add sub-commands:
   - `/fsub` or `/fsub list` : Shows currently connected channels and invite status.
   - `/fsub remove <channel_id>` : Removes a single channel without wiping all 5.
   - `/fsub clear` : Clears all force-sub channels for that group.
3. User Verification Button:
   When user is prompted to join channels, include a callback button:
   `[ ✅ I Have Joined ]` which immediately re-checks membership and sends the file
   without forcing the user to re-type the search query.

BENEFIT:
Seamless administrative control and higher channel join conversion rates.

6. PRIORITY 5: TELEGRAM IN-APP WEBAPP STREAMING (EMBEDDED PLAYER)
================================================================================
PROBLEM:
Tapping the streaming URL opens an external mobile browser, interrupting the
Telegram chatting experience.

SOLUTION / UPGRADE SPEC:
1. Use Pyrogram's `InlineKeyboardButton(text="▶️ Watch Online", web_app=WebAppInfo(url=stream_url))`.
2. Inside `req.html`, Telegram WebApp SDK (`telegram-web-app.js`) automatically
   adjusts to Telegram's viewport theme (dark mode / light mode).
3. Keep the `⚡ 1DM / Fast DL` button prominent inside the WebApp player so users
   who want external multi-threaded downloads still have 1-tap access.

BENEFIT:
Native, premium user experience that keeps users directly inside your Telegram bot.

8. PRIORITY 7: UNIQUE HASH DUPLICATE DEDUPLICATION IN MONGODB
================================================================================
PROBLEM:
Multiple source channels often contain the identical file with slightly different
channel watermarks or file names, creating duplicate clutter.

SOLUTION / UPGRADE SPEC:
1. Telegram provides `file_unique_id` for every document and video.
2. During indexing (`plugins/index.py` or `/index` command):
   - Check if `file_unique_id` or `(file_size, file_duration)` already exists in MongoDB.
   - If it exists, append the new name as an alias/alternate keyword rather than
     inserting a separate database document.

BENEFIT:
Saves MongoDB database storage, keeps indexes fast, and prevents duplicate button rows.
